# 🎙️ Cromak Bridge Vox

O **Cromak Bridge Vox** é um assistente desktop inteligente desenvolvido para oferecer interação multimodal contínua (voz e texto), persistência local segura e suporte aprimorado a recursos de acessibilidade.

---

## ✨ Recursos Principais

- 🗣️ **Interação por Voz e Texto:** Entrada e resposta por síntese e reconhecimento de voz.
- 🗄️ **Armazenamento Local:** Histórico e preferências gerenciados localmente via SQLite.
- ♿ **Foco em Acessibilidade:** Interface ergonômica, compatível com navegação por teclado e leitores de tela (NVDA/JAWS).
- 🔒 **Privacidade & Segurança:** Controle de chaves de API e operação offline-first para rotinas locais.

---

## 🚀 Como Executar

### Pré-requisitos
- Python 3.10+ (ou ambiente configurado)
- Dependências listadas no `requirements.txt`

### Instalação
```bash
# Clone o repositório
git clone [https://github.com/CromakTechnology/cromak-bridge-vox.git](https://github.com/CromakTechnology/cromak-bridge-vox.git)

# Acesse a pasta
cd cromak-bridge-vox

# Instale os requisitos
pip install -r requirements.txt

# Inicie o assistente
python main.py
