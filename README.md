## 📖 Visão Geral

O **Cromak Bridge Vox** é um **Agente Autônomo de Inteligência Artificial para Desktop** projetado do zero para oferecer interação multimodal contínua (voz, texto, visão de tela e arquivos), persistência local segura e **acessibilidade extrema** para pessoas com deficiência visual (cegueira e baixa visão).

Diferente de um simples chat restrito a uma aba de navegador, o Bridge Vox atua como um **Agente de Sistema Operacional integrado ao Windows**. Ele foi concebido como uma evolução moderna de projetos pioneiros de acessibilidade (como o histórico DOSVOX), mas alimentado pelo estado da arte dos modelos fundacionais globais através de arquitetura **BYOK (Bring Your Own Key)** — garantindo acesso ultra-rápido com a tecnologia LPU da **Groq**, bem como **Google Gemini 2.5**, **OpenAI ChatGPT**, **Anthropic Claude** e **Alibaba Qwen Cloud**.

### Recursos de Inclusão Nativa:
- 🎯 **WAI-ARIA `role="application"` & Modo de Foco Automático:** A interface opera com `role="application"` para instruir leitores de tela como NVDA e JAWS a alternarem automaticamente para o **Modo de Foco**, permitindo que as teclas de atalho cheguem diretamente à aplicação sem interceptação pelo Modo de Navegação virtual (*Browse Mode*).
- 💡 **Dica de Operação para NVDA:** Caso o leitor de tela NVDA não responda aos atalhos de navegação direta, certifique-se de alternar para o Modo de Foco pressionando **`NVDA + Barra de Espaço`**.
- 🔊 **NVDA & Narrador do Windows:** Live Regions ARIA dedicadas para que cada token gerado e finalização de resposta seja anunciado ao usuário de forma imediata e fluida, sem eco.
- 🌐 **Internacionalização em 11 Idiomas & Auto-detecção:** Detecta automaticamente o idioma do sistema operacional no primeiro uso. Toda a interface, atalhos e falas de leitor de tela se adaptam instantaneamente.
- 🛑 **Encerramento Acessível e Seguro (F4 / Alt+F4 / Ctrl+Q):** Diálogo de confirmação acessível com anúncio prioritário no NVDA (Enter para fechar, Esc para cancelar), prevenindo fechamentos acidentais.
- ⌨️ **Operação 100% por Teclado (WCAG 2.1.4):** Foco automático contínuo na caixa de entrada, teclas modificadoras alternativas para todos os atalhos e proteção estrita contra disparo de letras soltas durante a digitação.
- 🌓 **Modo Alto Contraste para Baixa Visão:** Fundo 100% preto com tipografia e bordas em amarelo vibrante, proporcionando máximo conforto ocular e zero poluição visual.
- 🗣️ **Síntese & Reconhecimento de Voz:** Ditado por atalho global e síntese de voz nativa opcional com volume e velocidade calibrados.

## ✨ Recursos & Funcionalidades Principais

- 🤖 **Auto-Coder & Agente Local:** O agente é capaz de inspecionar diretórios, criar scripts em Python, PowerShell ou Batch, editar documentos e automatizar tarefas repetitivas diretamente no computador.
- 📁 **Pesquisa Profunda de Arquivos:** Encontra documentos no disco rígido do usuário mesmo quando a busca do Windows falha ou quando a extensão do arquivo é omitida.
- 👁️ **Visão Computacional Multimodal:** Anexe fotos, gráficos, PDFs ou ordene que o assistente capture a tela ativa para descrever layouts, transcrever textos e explicar imagens.
- 📅 **Agenda Pessoal Offline com Alarme:** Gerenciador de tarefas e compromissos integrado com banco SQLite local, disparando alertas sonoros e notificações 15 minutos antes dos eventos.
- ⚡ **Velocidade LPU em Milissegundos:** Suporte nativo à infraestrutura ultra-rápida da **Groq**, permitindo que pessoas que utilizam leitores de tela naveguem e obtenham respostas sem tempos de espera incômodos.
- 🔒 **Zero Telemetria (Local-First):** Suas conversas, chaves de API e arquivos **nunca** passam por servidores intermediários da Cromak Technology. Todas as requisições saem do seu computador diretamente para a API oficial do provedor selecionado.

## 🌐 Internacionalização Nativa (11 Idiomas & Detecção Automática)

O **Cromak Bridge Vox** foi projetado para alcançar usuários e desenvolvedores ao redor do mundo com autonomia e acessibilidade completas:

- **Detecção Automática do Windows:** Na primeira execução, o software identifica a API de idioma do Windows (`GetUserDefaultUILanguage`) e já inicia automaticamente na língua nativa do usuário (sem exigir nenhuma configuração prévia).
- **Troca Dinâmica em Tempo Real:** No painel de Configurações (<kbd>F10</kbd>), o usuário pode alternar o idioma a qualquer instante — toda a interface gráfica, botões, placeholders e anúncios sonoros do leitor de tela são atualizados em milissegundos sem fechar o programa.
- **Ecossistema Aberto (`web/locale/`):** Qualquer desenvolvedor ou tradutor pode adicionar novos idiomas criando arquivos `.json` estruturados na pasta de idiomas.

## 🚀 Como Executar

### Opção 1: Instalador Oficial para Windows (Recomendado)
Para a maioria dos usuários, não é necessário instalar Python ou configurar bibliotecas manualmente:
1. Acesse a seção de downloads no [Site Oficial da Cromak Technology](https://cromaktechnology.github.io/pt/bridge-vox.html#planos).
2. Baixe o instalador oficial (`Instalador_Cromak_Bridge_Vox_v1.3.5.exe`).
3. Execute o instalador (100% acessível pelo teclado com o botão **Instalar**).
4. O programa iniciará automaticamente e criará os atalhos na Área de Trabalho e Menu Iniciar.

---

### Opção 2: A partir do Código-Fonte (Desenvolvedores)

#### Pré-requisitos
- **Windows 10 ou 11 (64-bits)**
- **Microsoft Edge WebView2 Runtime:** Nativo no Windows 10 e 11 padrão. Em edições especializadas como **Windows 10 LTSC**, **Windows Server** ou **Windows IoT Enterprise**, é necessária a instalação avulsa do [Microsoft Edge WebView2 Evergreen Bootstrapper](https://go.microsoft.com/fwlink/p/?LinkId=2124703).
- **Python 3.10 ou superior** instalado e adicionado ao `PATH`
- **FFmpeg (64-bits):** Essencial para captura e conversão de áudio, transcrição de voz pelo microfone, síntese e download de mídia. Coloque `ffmpeg.exe` e `ffprobe.exe` dentro da pasta `plugins/ffmpeg/` (ou adicione-os ao `PATH` do Windows).
- Conexão com a internet para requisições às APIs dos provedores

#### Passo a Passo

```bash
# 1. Clone o repositório
git clone https://github.com/CromakTechnology/cromak-bridge-vox.git

# 2. Acesse o diretório do projeto
cd cromak-bridge-vox

# 3. Crie e ative um ambiente virtual isolado (recomendado)
python -m venv .venv
.venv\Scripts\activate

# 4. Instale as dependências do projeto
pip install -r requirements.txt

# 5. Dependência de Mídia (FFmpeg):
# Baixe os binários oficiais em https://www.gyan.dev/ffmpeg/builds/ e copie
# 'ffmpeg.exe' e 'ffprobe.exe' para a pasta 'plugins/ffmpeg/'

# 6. Inicie o Cromak Bridge Vox
python main.py
```

Ao iniciar pela primeira vez, o assistente solicitará a configuração da sua chave de API preferida. Você pode utilizar chaves gratuitas:

- **Groq (Recomendado para ultra-velocidade):** Obtenha gratuitamente em [console.groq.com](https://console.groq.com/keys).
- **Google Gemini:** Gere sua chave gratuita no [Google AI Studio](https://aistudio.google.com/app/apikey).

- **Anthropic Claude:** Disponível em [console.anthropic.com](https://console.anthropic.com/).

## 🔒 Segurança e Privacidade

- **Arquitetura Zero Telemetria:** Nenhum dado de áudio, texto, arquivos ou histórico é enviado para servidores intermediários da Cromak Technology.
- **Isolamento de Credenciais:** As chaves de API nunca são expostas na interface pública ou sincronizadas em nuvem. Criptografia em repouso atrelada à máquina local via `%APPDATA%\Cromak Technology\Bridge Vox\config.json`.
- **Aviso sobre o Auto-Coder:** O Modo Agente possui permissões de execução de scripts locais e manipulação de arquivos a pedido expresso do usuário. Recomenda-se cautela ao autorizar comandos destrutivos.
- 🛡️ **Política Completa:** Consulte nosso [SECURITY.md](SECURITY.md) para detalhes exaustivos sobre a distinção entre processamento estritamente local e chamadas de nuvem, além das diretrizes para reporte responsável de vulnerabilidades.
